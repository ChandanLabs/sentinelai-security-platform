# Demo Script

*Note: This is the planned demonstration flow for the final project. It is not implemented yet.*

## Planned Flow
1. Login to the platform.
2. View the initial dashboard (empty or baseline state).
3. Generate normal activity (background noise).
4. Inject synthetic suspicious events.
5. System processes events through rule-based detection.
6. AI anomaly detection kicks in, outputting an anomaly score.
7. System calculates the final Risk Score.
8. System generates an Alert.
9. Analyst creates/opens an Incident for the Alert.
10. Analyst investigates the incident.
11. Analyst resolves the incident.
12. Review the Audit trail for the analyst's actions.
