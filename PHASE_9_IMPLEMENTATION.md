# Phase 9 — Frontend Security Dashboard

## Implemented
- Next.js/TypeScript security operations console.
- Login and registration flows using the existing JWT/refresh-token APIs.
- Browser token storage with automatic refresh on HTTP 401.
- Protected dashboard route with role display and logout.
- Overview KPI cards for events, alerts, incidents, and risk posture.
- Signal activity visualization with Recharts.
- Detection pipeline visualization.
- Live event, alert, and incident tables backed by Spring Boot APIs.
- Dark enterprise security-console design using the locked SentinelAI palette.
- Responsive sidebar/mobile navigation.
- API base URL configurable with `NEXT_PUBLIC_API_URL`.

## Scope boundary
Phase 9 focuses on the operational dashboard and read-oriented views. Advanced CRUD administration, event ingestion UI, alert/incident workflow controls, and richer filtering can be expanded in later hardening/polish work without changing the backend contract.
