# UI Design System

## Theme
Dark enterprise security console.

## Colors
- **Background:** `#0B1020`
- **Surface:** `#111827`
- **Primary:** `#6366F1`
- **Success:** `#22C55E`
- **Warning:** `#F59E0B`
- **Danger:** `#EF4444`
- **Text:** `#F8FAFC`
- **Muted:** `#94A3B8`

## Fonts
- **Inter:** Used for normal UI (headings, paragraphs, standard text).
- **JetBrains Mono:** Used for logs, event IDs, timestamps, IP addresses, and technical values.

## Design Principles
- **Professional:** Look like an enterprise tool.
- **Minimal:** Avoid clutter; prioritize information.
- **Readable:** High contrast, clear typography.
- **Accessible:** Follow WCAG guidelines for contrast and navigation.
- **Data-focused:** Optimize for viewing dense data like logs and alerts.
- **Consistent:** Standardized components across all views.
- **Responsive:** Fluid layouts suitable for desktop security operations.
